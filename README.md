## GPT 桌宠

- 待机呼吸和眨眼，挥手打招呼，蓄力弹跳。
- 左右移动采用双脚跃行，两只帽角与折尖保持可见。
- 委屈、捧手等待、托腮思考和检查结果的独立动作。
- 十六方向转头，保留原有黑色椭圆眼睛。
- 用欢呼嘴形和动作表达“Hi-ho！”，图集不包含音频。

![左右跃行](GPT/HIHO-movement.gif)

把解压后的 `HIHO.png` 作为自定义桌宠图集导入支持 v2 图集的 GPT Pets 客户端。浮窗、鼠标跟随和工作状态切换由宿主客户端提供。

视线从上方 0° 开始，每隔 22.5° 一帧；90° 为屏幕右侧，180° 为下方，270° 为屏幕左侧。
