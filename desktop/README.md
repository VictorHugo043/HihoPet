# Hiho 桌面应用

Electron + TypeScript 实现的透明桌宠。共享动画、手势识别和互动逻辑位于同一代码目录；macOS 提供开发预览，Windows 待验证和打包。

## 打开 macOS 应用

将预览包解压，双击 `Hiho.app`。也可以将它拖到“应用程序”文件夹后打开。菜单栏蓝色小图标提供与右键相同的控制菜单。

预览包使用本地临时签名，尚未通过 Apple 公证；其他 Mac 可能会阻止打开。

## 互动

| 操作 | 反应 |
| --- | --- |
| 单击 | 随机播放独立的 Hi-ho 叫声，头顶弹出对应文字；连点时播完当前声音再接下一种 |
| 双击 | 蓄力跳跃，落地回弹 |
| 轻柔地在头上来回移动鼠标 | 舒服地眯眼，冒出小爱心 |
| 连续五分钟没有互动 | 慢慢睡着，单击可轻轻叫醒；聆听音乐时保持清醒 |
| 拖起并移动 | 悬空挣扎，随移动方向摇晃，松手后回弹 |
| 按住并快速来回拖动 | 约两秒内往返摇晃数次，每次移动至少约 25 像素；松手后转晕，带着低落的叫声慢慢醒来，再生气跺脚、消气 |
| 在周围连续绕圈移动鼠标 | 眼睛与脸朝向鼠标，约两圈后转晕；可先拖到屏幕中间，留出绕圈空间 |
| 右键“喂一颗雪球” | 看着雪球飞过来，接住后开心回应 |
| 右键“逗逗它” | 追着附近的鼠标轻轻蹦跳，十五秒后休息；拖起或右键可随时停止 |
| 右键“跟着音乐动” | 底部固定在原地，身体随系统音量压缩、变宽和伸展；声音越大幅度越大，右键可停止 |
| 右键“⚡️‌HIHOの酒⚡️‌” | 直接播放内置的《朋友的酒》DJ 音频，坐姿随音量 Q 弹形变并轻微透视摇转；再次选择可停止 |

右键还可跳舞、睡觉／叫醒、开启安静模式、切换三档大小和退出。安静模式保留叫声文字。透明区域的鼠标事件穿透到下方应用；位置、大小和安静模式保存在系统应用数据目录中。

## 音乐律动

点击“开始聆听”后，系统可能请求音频权限。应用只在本机分析系统声音的强弱和节奏，不保存或上传音频、不使用麦克风。声音停止后，动作逐渐平静；退出应用后停止采集，重新启动需主动开启。

系统聆听优先识别 40–180 Hz 低频鼓点，用短暂的峰值确认和拍点间隔过滤连续小波动；没有明显鼓点时，随整体声音的起伏轻柔律动。实时分析需要等待声音到达，拍点会有少量检测延迟。

“⚡️‌HIHOの酒⚡️‌”直接播放包内的 `assets/hiho-song.mp3`，不需要联网、选曲或系统音频采集权限；分析歌曲原始音量，安静模式保留动画并静音播放。播放结束或再次选择菜单项时停止。音频出处：[BV1hXbN6VEKV](https://www.bilibili.com/video/BV1hXbN6VEKV/)。角色的旋转为底部固定的网格透视摇转，不包含可展示背面的完整三维模型。

本地歌曲预先分析重拍与音量，并按声音输出设备的播放时钟取样。身体在重拍前连续压缩，在拍点触底，再伸展回弹；音量决定幅度。角色直接由 WebGL 绘制，对话与特效使用独立透明画布。

Chromium 要求同时申请视频轨道：应用仅将自己的控制窗口作为视频源，取得后立即停止该轨道，不读取桌面画面。音频捕获能力取决于 macOS 与 Electron 支持；被拒绝时窗口会显示重试说明。

## 本地开发

需要 Node.js 22.12 或更高版本、npm。macOS 打包需要系统自带的 `codesign` 与 `ditto`。

```sh
cd desktop
npm ci
npx install-electron
npm test
npm start
```

```sh
npm run package:mac
```

生成 `out/Hiho-darwin-arm64/Hiho.app` 与 `out/Hiho-macOS-arm64.zip`（Apple Silicon）；在 Intel Mac 上构建时架构为 `x64`。输出目录不进入 Git。

`src/shared/behavior.ts` 处理互动状态和手势；`src/shared/motion.ts` 驱动连续动作；`src/artwork.ts` 用一张连通的角色网格绘制身体，保留颈部像素。系统音乐仅传递节奏数值给桌宠窗口。
