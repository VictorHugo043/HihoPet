# Hiho macOS 安装说明

## 适用设备

- Apple Silicon Mac（M1、M2、M3、M4 及更新的 M 系列芯片），macOS 13 或更新版本。
- 在苹果菜单的“关于本机”中查看“芯片”和系统版本。Intel Mac 不适用这个 arm64 包。
- “跟着音乐动”建议使用 macOS 14.2 或更新版本，并允许系统音频录制；基础互动与内置歌曲播放无需这项权限。
- 无需安装 Node.js、Electron 或其他开发工具。

## 下载与安装

1. 从本项目的 [GitHub Releases](https://github.com/VictorHugo043/HihoPet/releases) 下载文件名以 `-macOS-arm64.zip` 结尾的包。不要选择 GitHub 自动生成的 `Source code` 源码压缩包。
2. 双击 ZIP 解压，打开解压后的 `Hiho-版本-macOS-arm64` 文件夹。
3. 将里面的 `Hiho.app` 拖到访达的“应用程序”文件夹。
4. 在“应用程序”中双击 `Hiho.app`。Hiho 会出现在桌面右下角，可以直接拖动它。应用不显示 Dock 图标，菜单栏有蓝色小图标。

应用包采用 ad-hoc 本地签名，尚未使用 Apple Developer ID 签名或通过 Apple 公证，首次打开可能被 macOS 拦截。

## 首次打开被拦截

如果出现“无法验证开发者”或“Apple 无法验证此 App 是否包含恶意软件”等提醒：

1. 确认文件来自上面的项目 Release 页面，并先尝试打开一次 `Hiho.app`。
2. 打开“系统设置 → 隐私与安全性”，向下找到安全性区域。
3. 在 Hiho 的拦截提示旁选择“仍要打开”，按系统提示认证并选择“打开”。

详细步骤见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

如果提示“Hiho 已损坏，无法打开”，先重新下载并校验文件。确认下载完整且信任本发布包后，若系统仍未提供“仍要打开”，可以在“终端”中手动执行：

```sh
xattr -dr com.apple.quarantine "/Applications/Hiho.app"
```

然后重新双击应用。此命令仅移除指定 Hiho.app 的下载隔离标记。若提示“将损坏你的电脑”、校验不一致或移除标记后仍无法打开，请停止运行并在仓库反馈错误信息。

## 文件校验

从同一 Release 下载 `SHA256SUMS.txt`，与 ZIP 放在同一文件夹。在“终端”进入该文件夹，例如：

```sh
cd ~/Downloads
shasum -a 256 -c SHA256SUMS.txt
```

列出的文件均显示 `OK` 表示下载内容与发布时一致；这项校验不等同于 Apple 公证。

## 开始使用

- 单击 Hiho：随机叫出 Hi-ho，并弹出对应对话条；双击会跳跃。
- 拖动可移动位置，快速来回摇晃或在周围持续绕圈会把它逗晕。
- 轻轻来回摸头会眯眼；右键可喂雪球、逗它追鼠标、跳舞、睡觉、调整大小或开启安静模式。
- 五分钟没有互动会睡着，睡姿有缓慢呼吸起伏；单击可叫醒。
- 右键“⚡️‌HIHOの酒⚡️‌”直接播放内置歌曲并坐着 Q 弹律动，再次选择即可停止。安静模式保留动作并静音播放。
- 右键“退出 Hiho”关闭应用。找不到角色时，也可点击菜单栏蓝色图标打开相同菜单。

## 跟随系统音乐

1. 右键 Hiho，选择“跟着音乐动”。
2. 在控制窗口点击“开始聆听”，允许 macOS 请求的系统音频录制权限。
3. 在音乐播放器或浏览器中播放歌曲。Hiho 会坐着随鼓点压缩与回弹，音量决定幅度。开头和突然变速时需要短暂识别节奏。
4. 右键选择“停止跟随音乐”即可停止。

若没有反应，在“系统设置 → 隐私与安全性 → 屏幕与系统音频录制”（部分版本显示为“系统音频录制”）中检查 Hiho 的权限。修改后退出并重新打开 Hiho，再手动开启聆听。菜单名称随 macOS 版本可能不同。

应用仅在主动开启后，在本机分析系统播放的声音，不使用麦克风、不保存或上传音频。Electron 需要同时申请视频轨道，Hiho 只将自己的控制窗口作为来源，并立即停止视频轨道。内置歌曲播放不需要系统音频采集权限。系统音频能力说明见 [Electron 文档](https://github.com/electron/electron/blob/v45.0.0/docs/api/desktop-capturer.md#macos-versions-142-or-higher)。

## 更新与卸载

- 更新：先通过右键菜单退出 Hiho，再用新版 `Hiho.app` 替换“应用程序”里的旧版，然后打开。应用没有自动更新功能。
- 位置、大小与安静模式保存在 `~/Library/Application Support/Hiho/`，替换应用会保留这些偏好；音乐播放与聆听需重新主动开启。
- 卸载：退出 Hiho，将“应用程序”里的 `Hiho.app` 移到废纸篓。需要同时清除偏好时，可在访达“前往 → 前往文件夹”中输入上面的路径，只移除 Hiho 文件夹。
